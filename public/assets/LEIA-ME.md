# Arte original DRC Suporte

Envie o arquivo otimizado `drc-logo.webp` para esta pasta. A página inicial já está preparada para usar este arquivo no cabeçalho e na área de destaque. Enquanto ele não estiver presente, o site mantém a marca textual de reserva e o ícone original. A versão `drc-logo-sombra.webp` pode ser adicionada aqui para futuros blocos em fundo claro.

A atualização de `public/listas.json` é manual e pontual: os produtos dentro das listas são gerenciados pelo Mercado Livre. O site não faz scraping das listas.
